# Oma Approved?

A small, funny website where you chat with Oma Hildegard (81), a disappointed but loving German grandma. Built for a university Generative AI course.

Tell her about your life and watch her approval meter and face react. She asks you questions back, so the conversation keeps going.

## The oven knob

The knob changes two things: the model's **temperature** and a short **mood instruction** for that setting.

| Knob | Mood | Temperature | Mood instruction |
|------|------|-------------|------------------|
| 1 | Sunday Church Oma | 0.2 | just back from church: strict, formal, proverbs |
| 2 | Everyday Oma (default) | 0.8 | her usual self |
| 3 | Eierlikör Oma | 1.4 | a few glasses of egg liqueur: giggly, rambling, *hicks* |

Note: the original brief said the knob should change *only* the temperature. Because temperature alone made only a subtle difference, the mood instruction was added on purpose. The site's info button and footer say so openly.

## Approval

The approval meter starts at 30/100. Each reply moves it by up to ±10, and the model is told to be decisive. The current approval is sent with every message, so her tone changes with it: fuming (0–10), scandalised (11–20), disappointed (21–40), skeptical (41–60), pleased (61–80), proud and beaming (81–100). If you share something genuinely serious, she drops the act, answers kindly, and the meter doesn't move.

Her face changes every 10 points: fuming (red face, steam, shaking), furious, appalled, disappointed, unimpressed, skeptical, warming up, pleased, delighted, proud, and beaming with hearts at 100.

If approval hits 0, she ragequits: she throws the recipe at you and storms off.

Otherwise the visit ends after 15 messages or when you click "Say goodbye". Oma then hands over her Schwarzwälder Kirschtorte recipe, which is hardcoded in `recipe.js` and never generated by the AI.

## Files

- `index.html`: page layout
- `style.css`: all styling, including the mobile layout
- `script.js`: chat, dial, approval meter, confession cards, ending
- `oma.js`: Oma's portrait as inline SVG with all facial expressions
- `recipe.js`: the hardcoded Kirschtorte recipe
- `api/chat.js`: Vercel serverless function that calls OpenAI (system prompt, mood and approval instructions)

Plain HTML, CSS and JavaScript. No frameworks, no build step, no npm dependencies.

## Deploy (GitHub + Vercel)

1. Upload all files to a GitHub repository, keeping the `api/` folder.
2. In Vercel, import the repository. Framework preset: **Other**. Leave the build and output settings empty.
3. Environment variables (Project → Settings → Environment Variables):
   - `OPENAI_KEY` (or `OPENAI_API_KEY`): required
   - `OPENAI_MODEL`: optional, defaults to `gpt-4.1-mini`
4. Deploy. If you add or change an environment variable later, redeploy so the function picks it up.

## Budget protection

- `max_tokens`: 200 per answer
- Only the system prompt plus the last 8 messages are sent to OpenAI
- Max 15 user messages per visit (frontend limit, and the server rejects longer histories)
- User input limited to 300 characters
- The server only accepts the temperatures 0.2, 0.8 and 1.4
- Best-effort rate limit of 40 requests per IP per 10 minutes (in memory, per function instance). Adjust `RATE_LIMIT_MAX_REQUESTS` in `api/chat.js` if needed.

The API key is only read on the server and is never in any file.
